## 👋 About Me

I'm **Anshita Singh**, an **AI/ML Engineer and aspiring Data Scientist** based in Kanpur, India, currently pursuing my B.Tech in Computer Science (CGPA 8.46). I build and ship computer vision pipelines — **YOLO, U-Net, CNNs** — for real-world healthcare applications, including a live diagnostic workflow at **Rayoscan AI Diagnostics**. - 💬 Ask me about YOLO, U-Net, image segmentation, or model deployment
